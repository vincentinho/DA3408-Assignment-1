The model that best performed was the last one, that is, run number six. With an accuracy of 97.3%, hidden_layer_size set to 200 and max_iter set to 500, we can observer that, when compared to the models with a higher hidden_layer_size, run6 underfitted slightly less. Furthermore, this shows us that this model was able to learn more signal from the training at the same time that it managed to keep its noise accumulation to a lesser extent than the other models. Regarding the number of maximum iterations, 500, it did not contain the highest value out of all the models, that being of 1000 for run1 and run4. However, despite being half of the latter two, it did not seem to affect the accuracy of the model as much as the number of hidden layers, given that the accuracy of run4 was 95.4% and run1 was 96.4%, where run1 had a higher value for hidden layers then run4.
